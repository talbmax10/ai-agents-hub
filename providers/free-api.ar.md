# 🆓 مزودو API مجانيون أو بخطة مجانية للنماذج

هذه الصفحة تجمع مزودين يقدمون نماذج مجانية أو خطة مجانية. **المجاني لا يعني غير محدود**؛ فالحدود والنماذج المؤهلة والأسعار والسياسات قد تتغير. تحقق دائمًا من لوحة المزود الحالية قبل الاعتماد عليه.

## 1. Google AI Studio / Gemini API

**مناسب لـ:** أسهل بداية للحصول على مفتاح API وتجربة نماذج Gemini.

### إنشاء مفتاح API
1. افتح Google AI Studio.
2. سجّل الدخول بحساب Google.
3. افتح قسم مفاتيح API.
4. أنشئ مفتاحًا جديدًا وانسخه فورًا.
5. خزّنه كمتغير بيئة ولا تضعه في Git.

### اختيار النموذج
استخدم قائمة النماذج الحالية في AI Studio والتوثيق الرسمي. ابدأ عادةً بنموذج Gemini Flash حديث للتجارب السريعة، واختر نموذجًا أقوى عندما تكون الجودة أهم من السرعة.

```bash
export GEMINI_API_KEY="YOUR_KEY"
```

التوثيق الرسمي: https://ai.google.dev/

## 2. Groq

**مناسب لـ:** الاستدلال السريع وتجارب الوكلاء واستدعاء الأدوات عندما يكون النموذج المطلوب متاحًا.

### إنشاء المفتاح
1. أنشئ/افتح حساب Groq.
2. افتح صفحة API Keys في لوحة التحكم.
3. أنشئ مفتاحًا.
4. خزّنه باسم `GROQ_API_KEY`.

```bash
export GROQ_API_KEY="YOUR_KEY"
```

### اختيار النموذج
اختر من قائمة النماذج الحالية في لوحة Groq؛ التوفر وحدود الخطة المجانية قد تتغير.

التوثيق: https://console.groq.com/docs

## 3. OpenRouter

**مناسب لـ:** نقطة API واحدة للوصول إلى عدد كبير من المزودين والنماذج، ومنها النماذج التي يظهر سعرها حاليًا كمجاني.

### إنشاء المفتاح
1. أنشئ/افتح حساب OpenRouter.
2. افتح صفحة Keys.
3. أنشئ مفتاحًا.
4. خزّنه باسم `OPENROUTER_API_KEY`.

```bash
export OPENROUTER_API_KEY="YOUR_KEY"
```

### اختيار النموذج
افتح قائمة Models واستخدم فلتر الأسعار لاختيار النماذج التي يظهر لها حاليًا سعر إدخال/إخراج صفري أو وسم Free. لا تفترض أن نموذجًا سيبقى مجانيًا دائمًا.

عنوان API:

```text
https://openrouter.ai/api/v1
```

التوثيق: https://openrouter.ai/docs

## 4. Cerebras

**مناسب لـ:** الاستدلال السريع عندما تكون الخطة المجانية/التطويرية والنموذج المطلوب متاحين لحسابك.

### إنشاء المفتاح
1. أنشئ/افتح حساب Cerebras.
2. افتح قسم المطور أو API Keys.
3. أنشئ مفتاحًا.
4. خزّنه باسم `CEREBRAS_API_KEY`.

```bash
export CEREBRAS_API_KEY="YOUR_KEY"
```

تحقق من قائمة النماذج والحدود الحالية في التوثيق الرسمي.

التوثيق: https://inference-docs.cerebras.ai/

## 5. Cloudflare Workers AI

**مناسب لـ:** التطبيقات التي تعمل أصلًا على Cloudflare Workers.

### الإعداد
1. أنشئ/افتح حساب Cloudflare.
2. أنشئ أو اختر مشروع Workers.
3. فعّل Workers AI واتبع إعداد الـbinding الحالي.
4. اختر نموذجًا من الكتالوج الحالي.
5. لا تكشف الرموز المميزة ذات الصلاحيات في كود المتصفح.

التوثيق: https://developers.cloudflare.com/workers-ai/

## كيف تختار؟

| الحاجة | ابدأ بـ |
|---|---|
| أسهل مفتاح API | Google AI Studio |
| استدلال سريع | Groq / Cerebras |
| نماذج كثيرة عبر API واحد | OpenRouter |
| تطبيق Cloudflare | Workers AI |

## قواعد اختيار النموذج للوكلاء

- استخدم متغيرات البيئة للمفاتيح.
- تأكد أن الوكيل يدعم تنسيق API الخاص بالمزود.
- في الوكلاء المتوافقين مع OpenAI استخدم عنوان Base URL ومعرّف النموذج الرسميين للمزود.
- ابدأ بنموذج سريع وصغير لاختبار الأدوات واستدعاء الوظائف.
- انتقل إلى نموذج أقوى بعد اختبار السياق وStructured Output وTool Calling.
- راقب حدود الطلبات والحصة؛ قد تتوقف الخطة المجانية بعد استهلاكها.

## الأمان

**لا تضع مفتاح API حقيقيًا داخل هذا المستودع.** استخدم `.env` محليًا، أو GitHub Actions Secrets، أو مدير الأسرار الموثق في الوكيل.
