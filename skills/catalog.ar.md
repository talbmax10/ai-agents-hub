# 🧰 كتالوج الأدوات والمهارات

كتالوج موسع لقدرات قابلة لإعادة الاستخدام مع وكلاء الذكاء الاصطناعي. يجب دائمًا التحقق من التوافق وطريقة التنصيب الحالية من المشروع الأصلي.

## المتصفح والويب

Playwright، Puppeteer، browser-use، Selenium، curl.

## البرمجة وأدوات المطور

Git، GitHub CLI، ripgrep، fd، jq، Docker، pytest.

## البحث والاسترجاع

Trafilatura، Scrapy، Beautiful Soup، LlamaIndex، LangChain.

## الذاكرة والبيانات

SQLite، PostgreSQL، Qdrant، Chroma، Redis.

## المراسلة والأتمتة

Telegram Bot API، Discord API، cron، n8n.

## Computer Use

PyAutoGUI وxdotool للتحكم بسطح المكتب في البيئات المدعومة.

## أنماط مهارات مقترحة

- **بحث عبر المتصفح:** browser-use + Playwright + استخراج النص + التحقق من المصادر.
- **البرمجة:** Git + GitHub CLI + ripgrep + الاختبارات + بيئة معزولة.
- **RAG:** LlamaIndex/LangChain + Qdrant/Chroma + استخراج المستندات.
- **وكيل بعيد:** Telegram/Discord + webhook + جدولة + أقل صلاحيات ممكنة.
- **تنفيذ آمن:** Docker + موافقة صريحة على الأوامر المدمرة.

## تصنيفات التوافق

- ✅ Native — دعم أصلي موثق.
- 🔌 MCP — عبر خادم MCP.
- 🧩 Plugin — عبر إضافة/ملحق.
- 🛠️ Manual — عبر Shell أو API.
- ❓ Unverified — لم يتم التحقق منه بشكل مستقل.

الكتالوج ليس ضمانًا أمنيًا أو ضمان توافق شامل. افحص الصلاحيات والشبكة والتبعيات وصيانة المشروع الأصلي.
