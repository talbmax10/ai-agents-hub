## ✨ What is AI Agents Hub?

AI Agents Hub is an open, organized catalog of modern AI agents and the ecosystem around them.

Instead of hunting through hundreds of repositories, you can use one place to:

- 🔎 **Discover** AI agents by category and interface.
- 🏆 **Compare and rank** agents using transparent editorial criteria.
- 📦 **Install** agents with concise, practical guides.
- 🔗 **Visit original repositories** instead of relying on mirrors.
- 🧩 **Find tools, skills, MCP servers and integrations** that work with agents.
- 🛠️ **Learn how to extend agents** with skills, tools, memory and automation.
- 🌍 **Read everything in English or Arabic** using the language buttons above.
- 🤝 **Contribute** new agents, tools, skills, fixes and reviews.

The goal is not to declare one universal winner. **The best agent depends on your workflow.**

## 🛍️ Tools & Skills Marketplace

The `skills/` directory is designed like a small open-source store: browse a capability, see which agents it supports, open the original project, and follow its installation instructions.

### Featured capability categories

- 🌐 **Browser & Web** — Playwright, browser automation, web research
- 🧠 **Memory & Context** — persistent memory, context retrieval, knowledge bases
- 🔌 **MCP** — Model Context Protocol servers and connectors
- 💻 **Coding** — repositories, Git, terminals, tests and CI
- 📁 **Files** — filesystem and document operations
- 🔍 **Research** — search, scraping and structured extraction
- 🖥️ **Computer Use** — desktop control and visual interaction
- 📡 **Messaging** — Telegram, Discord and other channels
- ⚙️ **Automation** — cron, webhooks and scheduled jobs

Every entry should link to the **original source** and state its compatibility instead of pretending that one integration works everywhere.

## 🚀 Quick Start

You do not install the Hub itself. It is a directory and knowledge base.

1. Choose an agent from [`agents/`](agents/README.md).
2. Open its original repository.
3. Follow the agent's official installation instructions.
4. Choose a model/provider supported by that agent.
5. Add capabilities from [`skills/`](skills/README.md).
6. Read the security notes before granting shell, browser, filesystem or network access.

For a consolidated installation guide, see [`docs/installation.md`](docs/installation.md).

---

## 🔐 Security First

AI agents can execute commands, edit files, access the network, browse the web, and sometimes control a computer. Treat an agent as software with meaningful privileges.

**Never paste API keys, passwords, private tokens, SSH keys, or personal secrets into issues or pull requests.** Prefer environment variables and the agent's documented secret-management mechanism.

See [`SECURITY.md`](SECURITY.md).
