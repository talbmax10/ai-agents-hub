## Ranking methodology

The editorial score considers: capability, extensibility, ecosystem, documentation, usability, openness, security posture, and project momentum. Scores are not scientific benchmarks and should not be interpreted as objective performance measurements.

## How to evaluate an agent

1. **Task fit:** coding, research, automation, personal assistant, or computer use.
2. **Control:** human approval, sandboxing, permissions and command execution.
3. **Extensibility:** tools, skills, MCP, plugins and APIs.
4. **Model flexibility:** provider/API compatibility.
5. **Persistence:** memory, sessions, background jobs and scheduling.
6. **Operational maturity:** documentation, releases, tests and issue activity.
7. **License:** verify the upstream project's current license before commercial use.
