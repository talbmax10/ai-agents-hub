# 🏆 Ranking Methodology

AI Agents Hub uses an editorial score to make discovery easier. It is **not** a benchmark and does not represent the views of upstream maintainers.

## Criteria

| Criterion | Weight | What we look at |
|---|---:|---|
| Capability | 20% | Breadth and quality of agent behavior |
| Extensibility | 15% | Tools, skills, MCP, plugins, APIs |
| Ecosystem | 15% | Integrations and community resources |
| Usability | 15% | Setup, UX, CLI/web experience |
| Documentation | 10% | Quality and completeness of docs |
| Openness | 10% | Source availability and provider flexibility |
| Reliability | 10% | Stability, testing and operational maturity |
| Momentum | 5% | Recent releases and project activity |

Scores are rounded and should be revisited as upstream projects change.

## What the ranking is not

- Not a model leaderboard.
- Not a security certification.
- Not a guarantee that an agent is best for every task.
- Not an endorsement by any upstream project.

## Review policy

When possible, entries should record a `last reviewed` date and link to primary sources. Community submissions are welcome and should distinguish verified facts from opinions.
