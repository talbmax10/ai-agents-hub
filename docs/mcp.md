# 🔌 MCP Guide

Model Context Protocol (MCP) is an open protocol ecosystem for connecting AI applications and agents to tools and data.

## Why it matters

MCP can make a capability reusable across multiple agent hosts instead of rebuilding the integration for every agent.

## Before installing an MCP server

1. Check the original repository.
2. Read its permissions and security notes.
3. Inspect what files, network endpoints, credentials or commands it can access.
4. Pin or review versions when reproducibility matters.
5. Avoid running untrusted servers with broad privileges.

## Official ecosystem

- Model Context Protocol: https://github.com/modelcontextprotocol
- MCP documentation: https://modelcontextprotocol.io/

## Compatibility

An MCP server is not automatically compatible with every agent. Confirm that the host supports MCP and check the host's configuration format.
