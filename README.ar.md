> **أُنشئ AI Agents Hub لمحبي وكلاء الذكاء الاصطناعي.**
> هدفه جمع الوكلاء في مكان منظم مع روابط مستودعاتهم الأصلية، طرق التنصيب، التصنيف، الترتيب، الأدوات والمهارات والتكاملات.

## ✨ ماذا ستجد هنا؟

- 🔎 اكتشاف الوكلاء حسب النوع والاستخدام.
- 🏆 ترتيب تحريري قابل للمراجعة، وليس ادعاءً بوجود فائز مطلق.
- 📦 أدلة تنصيب عملية.
- 🔗 روابط مباشرة إلى المستودعات الأصلية.
- 🧩 متجر/دليل للأدوات والمهارات وMCP.
- 🌍 توثيق عربي وإنجليزي مع زر تبديل في واجهة الموقع.
- 🤝 مساحة مفتوحة للمساهمات والمراجعات والتحديثات.

## 🧰 متجر الأدوات والمهارات

دليل `skills/` مصمم كمتجر مفتوح المصدر: اختر القدرة، اعرف الوكلاء المتوافقين معها، ثم انتقل إلى المصدر الأصلي واتبع طريقة التنصيب.

التصنيفات تشمل: المتصفح، الذاكرة، MCP، البرمجة، الملفات، البحث، Computer Use، المراسلة، والأتمتة.

## 🚀 كيف أبدأ؟

1. اختر وكيلاً من [`agents/`](agents/README.md).
2. افتح مستودعه الأصلي.
3. اتبع تعليمات التنصيب الرسمية.
4. اختر النموذج أو مزود API المناسب.
5. أضف الأدوات والمهارات من [`skills/`](skills/README.md).
6. راجع الأمان قبل منح الوكيل صلاحيات الطرفية أو الملفات أو المتصفح أو الشبكة.

## 🔐 الأمان

الوكلاء قد ينفذون أوامر، يعدلون ملفات، يتصفحون الإنترنت أو يتصلون بخدمات خارجية. لا تضع مفاتيح API أو كلمات المرور أو مفاتيح SSH في Issues أو Pull Requests.

راجع [`SECURITY.md`](SECURITY.md).
