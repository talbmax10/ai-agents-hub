# Security Policy

AI Agents Hub is a directory and documentation project. It does not certify the security of listed agents, tools, skills or MCP servers.

## Reporting a problem in this repository

Do not publish exploitable details, credentials, API keys or private information in a public issue. Use GitHub's private security reporting features when available for this repository.

## Using listed agents safely

Agents may have the ability to execute commands, modify files, access networks, or interact with external services. Use least privilege, isolated workspaces, short-lived credentials, and sandboxing where appropriate.

Always inspect third-party tools and MCP servers before granting access to secrets or sensitive systems.
