# Contributing to AI Agents Hub

Thank you for helping build a better directory for the AI-agent community.

## What we accept

- New agents and agent frameworks
- Tools, skills and MCP servers
- Installation and compatibility notes
- Corrections to existing entries
- Benchmarks and reproducible comparisons
- Arabic/English translations
- Documentation and website improvements

## Quality rules

1. Prefer primary sources and official repositories.
2. Do not copy large portions of upstream documentation.
3. Clearly separate verified facts from opinions.
4. Include the upstream license when known.
5. Do not publish secrets, private information, or credentials.
6. Mention dangerous or privileged capabilities when relevant.
7. Keep rankings transparent and avoid undisclosed sponsorships.

## Adding an agent

Copy [`templates/agent.md`](templates/agent.md), complete it, and add the entry to `agents/README.md` or a dedicated file under `agents/`.

## Adding a tool or skill

Include:

- Name and category
- Original repository
- License
- Installation method
- Supported agents or protocols
- Required permissions
- Security notes

## Pull requests

Use a clear title such as `docs: add <agent>` or `feat: add <tool>`. Keep unrelated changes separate.
